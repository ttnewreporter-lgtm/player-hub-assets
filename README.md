# Player Hub Assets

Original, redistribution-safe SVG decorations for a personal adventure-themed Notion dashboard.

## Included

- One wide dashboard cover
- Six square page/database icons
- Source SVG only; no bundled Minecraft or Minecraft: Story Mode game files

Every asset in `assets/` was created specifically for this repository from simple geometric shapes. The designs use a generic pixel-adventure visual language and do not copy game textures, logos, screenshots, renders, music, or extracted files.

## Excluded after source audit

- Mojang/Microsoft Minecraft 1.21 texture files from the InventivetalentDev archive
- All files from **MCSM Items [vanilla]**, whose Modrinth project is marked All Rights Reserved
- Files from **MCSM Official Pack**. Although its Modrinth project is labeled MIT, the uploaded ZIP did not contain an MIT license and included credited third-party/menu material plus game-related audio and imagery; none of it is mirrored here
- The user's dashboard-reference screenshots and any proprietary MCSM renders

See [ATTRIBUTION.md](ATTRIBUTION.md) for the audit trail and [ASSET_MANIFEST.md](ASSET_MANIFEST.md) for Notion mappings.
